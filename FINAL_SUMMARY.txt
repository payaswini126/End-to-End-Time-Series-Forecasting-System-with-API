PROJECT OVERVIEW
----------------
A production-ready, end-to-end time series forecasting system that:
✓ Trains 4 different forecasting algorithms (SARIMA, Prophet, XGBoost, LSTM)
✓ Automatically selects the best model based on validation performance
✓ Exposes predictions via REST API with comprehensive documentation
✓ Handles missing data, seasonality, and trends
✓ Includes advanced feature engineering pipeline
✓ Ready for production deployment with Docker support
