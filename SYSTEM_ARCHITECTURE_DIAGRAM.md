## Data Flow Diagram

```
Excel File
    │
    ├─► Load Data (8,084 rows)
    │
    ├─► Preprocess
    │   ├─ Rename columns
    │   ├─ Convert dates
    │   └─ Sort data
    │
    ├─► Handle Missing Dates
    │   └─ Fill weekly gaps → 11,008 rows
    │
    ├─► Handle Missing Values
    │   └─ Forward fill → Backward fill → Mean
    │
    ├─► Split by State (43 states)
    │   └─ 256 weeks per state
    │
    ├─► Feature Engineering
    │   ├─ Create 38 features
    │   └─ Result: 256 rows × 41 columns
    │
    ├─► Time Series Split
    │   ├─ Train: 240 weeks
    │   ├─ Val: 8 weeks
    │   └─ Test: 8 weeks
    │
    ├─► Train Models (4 models)
    │   ├─ SARIMA
    │   ├─ Prophet
    │   ├─ XGBoost ★
    │   └─ LSTM (optional)
    │
    ├─► Evaluate & Select
    │   └─ Best: XGBoost (lowest MAPE)
    │
    ├─► Save Models
    │   └─ models/{state}_models.pkl
    │
    └─► API Serving
        └─ Generate 8-week forecast
```
